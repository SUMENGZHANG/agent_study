# Agent 开发学习计划

目标：能够独立设计、实现、调试和评测一个具备工作流、工具调用、RAG、记忆及流式输出能力的业务 Agent。

## 第一阶段：看懂固定工作流

- [ ] 第 1 课：Agent、LLM 应用和普通后端程序的区别
- [ ] 第 2 课：LangGraph 的 State、Node、Edge 与 Router
- [ ] 第 3 课：跟踪 `es-ai master` 的完整圈人调用链
- [ ] 第 4 课：结构化输出与 JSON/DSL 校验
- [ ] 阶段练习：实现一个不调用外部模型的最小圈人工作流

完成标准：可以自己画出 `master` 的 Graph，并解释一次请求中 State 如何变化。

## 第二阶段：模型与 Prompt

- [ ] LangChain、OpenAI SDK 和模型网关的职责区别
- [ ] System Prompt、User Prompt 与上下文构建
- [ ] Pydantic Structured Output
- [ ] Token、上下文长度、温度与模型选择
- [ ] 阶段练习：为维度拆解定义严格输入输出协议

完成标准：模型输出非法、字段缺失或类型错误时，程序能够明确失败。

## 第三阶段：RAG、标签检索与记忆

- [ ] Embedding、向量相似度和 Top-K
- [ ] 稠密、BM25、关键词三路召回
- [ ] 业务知识 RAG 与标签召回的区别
- [ ] Session、Turn、短期记忆与长期记忆
- [ ] 阶段练习：实现一个本地可运行的标签检索器

完成标准：能够解释召回率、准确率、阈值和重排，并设计基础评测样本。

## 第四阶段：工具调用与循环

- [ ] Tool Schema 与工具注册表
- [ ] 模型选择工具、程序执行工具、结果回填
- [ ] 循环次数、超时、取消和错误传播
- [ ] 阶段练习：增加日期范围工具并覆盖失败测试

完成标准：工具参数非法或调用失败时，工作流立即停止并返回明确错误。

## 第五阶段：Plan-Execute

- [ ] 阅读 `yili_audience_copilot` 的 `PlanExecuteState`
- [ ] Planner 如何生成计划
- [ ] Executor 如何执行步骤
- [ ] Should-Replan 如何重新规划
- [ ] Generate 与 Modify 两条业务路径
- [ ] 阶段练习：将固定工作流改造成简化 Plan-Execute

完成标准：可以比较固定 Pipeline、ReAct 和 Plan-Execute 的适用场景。

## 第六阶段：生产化

- [ ] FastAPI、SSE 与运行状态
- [ ] 身份认证、租户隔离和审计
- [ ] Trace、日志、Token 与成本统计
- [ ] 超时、取消、幂等、并发和限流
- [ ] Prompt/模型/工作流版本管理
- [ ] 黄金数据集、节点评测和端到端评测

完成标准：完成一个可观测、可取消、可评测的小型 Agent 服务。

## 学习记录模板

1. 今天解决了什么问题？
2. 核心概念是什么？
3. `es-ai` 中对应代码在哪里？
4. 我自己实现了什么？
5. 哪些地方仍然不理解？
6. 如果用于生产，还缺少什么？
